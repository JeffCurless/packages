Jeff Curless' packages

An APT repository for Jeff Curless' projects, for Debian, Ubuntu and Raspberry Pi OS.

Add the repository (all users)

Anyone can install these packages. Run the commands below once on each computer to add the repository; you don't need to repeat them.

sudo curl -fsSL https://jeffcurless.github.io/packages/public.gpg \
  -o /usr/share/keyrings/jeffcurless-packages.gpg
echo "deb [signed-by=/usr/share/keyrings/jeffcurless-packages.gpg] https://jeffcurless.github.io/packages stable main" \
  | sudo tee /etc/apt/sources.list.d/jeffcurless-packages.list
sudo apt update

Then install with sudo apt install <package>. Updates arrive with sudo apt update && sudo apt upgrade.
